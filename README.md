\*\*Game Description\*\*



\##### TIC-TAC-TOE(❌ ⭕) 





The game only has a one-on-one mode and is presented in a graphical interface for the players.



The game starts with an (X). The game ends when one of the players manages to make a line of either "X" or "O", or if there is a tie. It should allow the game to be repeated until the user finishes the game.

It should also allow viewing the history of all games played.<br>  



My idea was to be as most close as possible of the MVC.
